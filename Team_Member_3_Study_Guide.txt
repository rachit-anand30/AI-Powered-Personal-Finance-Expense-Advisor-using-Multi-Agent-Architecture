PART 1: OVERALL PROJECT EXPLANATION (PROJECT OVERVIEW)
--------------------------------------------------------------------------------

1. WHAT IS THIS PROJECT?
   The AI-Powered Personal Finance & Expense Advisor is a multi-agent web
   application designed to help individuals track, analyze, optimize, and
   forecast their personal finances automatically.

2. THE PROBLEM IT SOLVES:
   Most people face 4 major financial challenges:
   a) Lack of Visibility: Not knowing where their money goes each month.
   b) Fraud & Outliers: Missing suspicious or unusually large transaction charges.
   c) Poor Budgeting: Struggling to align spending with standard rules like 50/30/20.
   d) Lack of Foresight: Being unprepared for future spending trends.

3. MULTI-AGENT ARCHITECTURE (5 SPECIALIZED AGENTS):
   The application delegates tasks across 5 distinct AI agents:
   
   [1] Expense Analyzer Agent (Data Intelligence):
       - Automatically categorizes raw transactions (Food, Transport, Bills, etc.).
       - Computes spending metrics (monthly totals, daily average, % breakdown).
   
   [2] Anomaly Detection Agent (Security & Fraud Detection):
       - Uses Z-Score (statistical deviation) and Isolation Forest / IQR (outlier ML)
         to catch suspicious charges (e.g., an unexpected Rs 75,000 transaction).
   
   [3] Budget Planning Agent (Rules & Optimization):
       - Applies the 50/30/20 Rule (50% Needs, 30% Wants, 20% Savings).
       - Evaluates actual spending against targets and calculates a 0-100 Health Score.
   
   [4] Prediction Agent (Machine Learning Forecasting):
       - Analyzes historical monthly totals.
       - Uses Linear Regression (or Moving Average fallback) to forecast next month's
         expected expenses and projected savings.
   
   [5] Advisor Agent (Natural Language Communication):
       - Translates all analytical outputs into friendly, actionable advice,
         concrete rupee savings recommendations, and risk alerts.

4. SYSTEM STACK OVERVIEW:
   - Backend: Python + FastAPI + MongoDB (with in-memory fallback).
   - Frontend: React 18 + Vite + TailwindCSS + Recharts.

PART 2: TEAM MEMBER 3 - DETAILED EXPLANATION (YOUR SPECIFIC PART)

OVERALL ROLE:
As Team Member 3, you are the System Architect and Integrator. While Team Member 1
handled data intelligence/fraud detection and Team Member 2 handled budget rules/ML
forecasting, YOU built the orchestration engine, the backend API, the database layer,
the natural language advisor, and the full frontend user interface dashboard.

1. COORDINATOR AGENT (backend/agents/coordinator_agent.py):
   - Function: Serves as the central orchestrator / single entry point of the pipeline.
   - Execution Pipeline (5 Steps in Order):
       Step 1: ExpenseAnalyzerAgent -> Categorizes & aggregates metrics.
       Step 2: AnomalyDetectionAgent -> Flags suspicious transactions.
       Step 3: BudgetPlanningAgent -> Computes 50/30/20 split & health score.
       Step 4: PredictionAgent -> Computes ML forecast & trend.
       Step 5: AdvisorAgent -> Synthesizes natural language recommendations.
   - Fault Tolerance: Wrapped in try-except execution logging. If any single agent
     encounters invalid inputs, the Coordinator catches it gracefully and returns
     partial data with diagnostic logs instead of crashing with a 500 error.

2. ADVISOR AGENT (backend/agents/advisor_agent.py):
   - Function: Converts raw mathematical & ML outputs into human-readable advice.
   - Key Outputs Synthesized:
       a) Overall Summary: Evaluates the Budget Health Score (0-100).
       b) Top Recommendations: Provides up to 5 targeted recommendations.
       c) Savings Opportunities: Calculates concrete rupee savings (e.g., 25% cut on Food).
       d) Risk Narrative: Describes forward-looking risk based on prediction models.
       e) Custom Query Response: Addresses specific user questions if provided.
   - Advantage: Fully deterministic rule-based synthesis. Requires ZERO external paid
     LLM APIs (like OpenAI or Gemini), ensuring zero latency, zero cost, and zero AI
     hallucination risk.

3. BACKEND REST API & DATABASE LAYER:
   - Framework: FastAPI (Python async REST API).
   - 8 REST Endpoints:
       1) GET  /                        -> API Health check.
       2) POST /upload_transactions      -> Saves transactions and returns expense analysis.
       3) POST /analyze_expenses         -> Categorizes and calculates expense metrics.
       4) GET  /get_transactions/{id}    -> Retrieves transaction history for a user.
       5) POST /create_budget            -> Calculates 50-30-20 budget plan & score.
       6) POST /predict_expenses         -> Returns next month ML prediction.
       7) POST /get_financial_advice     -> Returns standalone natural language advice.
       8) POST /full_analysis            -> MASTER ENDPOINT: Triggers entire Coordinator pipeline.
   - Resilient Database Service (backend/services/database.py):
       - Uses Motor for asynchronous MongoDB connection.
       - Pings MongoDB on startup with a 2-second timeout.
       - If MongoDB is unreachable, it automatically falls back to an In-Memory Store
         (`use_memory = True`), guaranteeing 100% demo reliability without a running database.

4. FRONTEND UI DASHBOARD (frontend/src/):
   - Built with: React 18, Vite, TailwindCSS, Recharts, Lucide Icons.
   - 11 Modular Components:
       1) Header.jsx            -> Title, navigation tabs, and system health status.
       2) Dashboard.jsx         -> Main container grid layout.
       3) FinancialSummary.jsx  -> Key stat cards (Income, Total Spend, Score, Risk).
       4) ExpenseChart.jsx      -> Recharts pie & bar visualizations of category spending.
       5) BudgetAllocation.jsx  -> Visual progress bars for 50-30-20 Needs vs Wants vs Savings.
       6) BudgetPlan.jsx        -> Health score breakdown and overspending alert banners.
       7) PredictionGraph.jsx   -> Line chart plotting historical months vs. forecasted month.
       8) AIRecommendations.jsx -> Formatted panel displaying NL advice & savings tips.
       9) AnomalyAlerts.jsx     -> Risk level badges & list of flagged transactions.
      10) TransactionUpload.jsx -> Form to add manual transactions or upload CSVs.
      11) DemoScenarios.jsx     -> Interactive launcher pre-loaded with 4 test scenarios.
   - 4 Pre-Loaded Demo Scenarios:
       1) Normal Analysis Flow   -> Healthy spending breakdown.
       2) Fraud Detection Flow   -> Injected Rs 75,000 outlier flagged immediately.
       3) Budget Warning Flow   -> High spend relative to income (Rs 18,500 spend on Rs 20,000 income).
       4) Prediction Flow       -> Demonstrates 3+ month history with Linear Regression trend line.
